# 4단계: 위기단계 예측 기본 모델

- train 2,876명으로 학습(5겹 교차검증), val 360명으로 평가
- F = 말하기 특징 (스스로 꺼낸 감정 낱말 + 말하기 지표), T = 아이 대답 낱말(TF-IDF), F+T = 둘 다, QA = 질문+대답 낱말 (상담사 질문이 있는 경우의 참고치)
- 위험군 = 응급·학대의심. 기준점은 위험군의 80%를 찾도록 train에서 정함
- 정밀도@p% = 실제 현장의 위험군 비율이 p%라면, 모델이 '위험'이라고 한 아이 중 진짜 위험군 비율
